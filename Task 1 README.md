# Smart Reminder Application

## Overview

The Smart Reminder Application is a Python-based productivity tool that allows users to create, manage, and monitor reminders efficiently. The application supports multiple reminders, persistent storage, reminder status tracking, and automated notifications when scheduled times are reached.

## Features

* Add new reminders
* View existing reminders
* Delete reminders
* Reminder status tracking
* Automatic reminder notifications
* Date and time validation
* JSON-based data storage
* User-friendly command-line interface

## Technologies Used

* Python 3.x
* Datetime Module
* Time Module
* JSON Module

## How to Run

1. Install Python 3.x.
2. Run the Python script.
3. Select an option from the menu.
4. Add, view, or delete reminders.
5. Monitor reminders in real time.

## Applications

* Personal task management
* Academic scheduling
* Appointment reminders
* Meeting management
* Productivity enhancement
